# 遥测异常与传感器故障处置知识

> 用途：仿真验证与算法测试，不构成真实维修结论。

## 触发线索

数据缺失、冻结、跳变、超出物理范围、多个传感器互相矛盾，或质量标志显示故障。

## 核验要点

1. 检查时间戳单位、采样率、重复值、丢帧和数据龄期。
2. 使用冗余传感器、运动学约束和历史趋势进行交叉验证。
3. 区分传感器故障、通信问题、解析映射错误和真实状态突变。
4. 记录异常字段、原始消息引用、转换版本与置信度变化。

## 建议输出边界

- 降低受影响规则、预测和建议的置信度，明确列出不可用字段。
- 不用插值结果掩盖持续故障，也不将数据集真值标注描述成模型检测结果。
- 关键状态无法确认时回退到保守规则并请求人工核验。
