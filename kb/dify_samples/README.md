# Dify 导入样本文档

这组文件可以直接导入 Dify Dataset，作为本地知识库的最小样本。

## 文件清单

- `uav_intrusion_sop.md`
- `fast_approach_guide.md`
- `loitering_sop.md`
- `multi_sensor_case.md`

## 使用方式

把这些文件整体上传到 Dify 的 Dataset 中即可。建议建一个单独的数据集，例如：

- `fake-lattice-sop`
- `fake-lattice-response`

## 导入建议

1. 先创建一个 Dataset。
2. 点击导入文件。
3. 选择这 4 个 Markdown 文件。
4. 导入完成后，用关键词测试：
   - `警戒区`
   - `高速接近`
   - `盘旋`
   - `多传感器`
