# CASE_MULTI_SENSOR_001 多传感器联合确认案例

## 文档类型
CASE

## 案例背景
当同一目标被雷达、光电或其他传感器多次命中时，应优先汇总证据并提高态势置信度。

## 经过
1. 雷达先发现目标。
2. 光电设备随后确认同一目标。
3. 系统将多源证据合并，提升置信度。
4. 值班员优先采纳跟踪和复核动作。

## 结论
- 多源证据能显著提高目标判断置信度。
- 先融合证据，再决定任务动作。

## 推荐动作
- 汇总不同传感器证据。
- 统一目标轨迹与标识。
- 优先安排持续跟踪和人工复核。
